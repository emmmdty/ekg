## 一句话结论

论文的四章结构已经稳定，评测协议、公开对手和下游正控也已建立；但截至 8 月 31 日，
**前三个方法章都还没有形成“稳定超过多个对手”的最终结论**：Ch1 的方法增益小于种子波动，
Ch2 已逼近主锚且找到一个有实测上限支持的新周期，Ch3 点估计最高但评测集对稀有类别功效不足；
Ch4 已经得到可写入论文的系统结果。

因此，未来三天不平均分配时间：**主攻 Ch2，次攻 Ch3，Ch1 只做方法设计和低成本验证，
Ch4 作为附加章整理已有结果。**

## 一、论文总体计划

论文研究从文本构建 occurrence-level 事件图谱，并研究构建错误对下游的影响：

| 章 | 核心问题 | 预期方法贡献 | 主指标 | 当前定位 |
|---|---|---|---|---|
| Ch1 事件身份消解 | 哪些提及属于同一次事件？ | 关系感知的事件度量与难负例对比学习 | MUC F1 | 方法待重设计 |
| Ch2 事件关系抽取 | 事件间因果、子事件、时间关系是什么？ | 候选检索 + 精判别，结合位置/关系族自适应 | causal micro-F1 | **当前主攻章** |
| Ch3 事件事实性检测 | 事件是事实、可能、否定还是未知？ | 证据条件化判别与稀有类表征学习 | 五类 macro-F1 | 次主攻章 |
| Ch4 构建错误的下游代价 | 节点、边和事实性错误各损失多少？ | 配对干预、消费者依赖性与误差预算 | MRR / Hit@k | 附加系统章，主结论已成立 |

最终论文需要四类交付：每章的问题与方法；同协议的多个对手和消融；三种子与配对统计；
从论文表格可反查到数据、命令、commit 和 checkpoint 的复现实验档案。

## 三、逐章进展、低分原因与下一步

### Ch1：事件身份消解

#### 已完成内容

- 建立触发词成对判别、聚类、官方 coreference 评测和难例分析流水线；
- 定量发现官方口径下过并占错误的 63.5%，相同词形仍占大量难例；
- 先后测试局部语境池化、混淆度特征、长上下文和更大 RoBERTa；
- 修复训练配方：warmup + 线性衰减使 10 个 epoch 的平均 MUC 提高 1.78 点，并明显降低 epoch 波动。

#### 当前指标

| 系统 | MUC F1 | 说明 |
|---|---:|---|
| official joint | **80.98** | 同协议对手 |
| 稳定底座 | **79.14** | 四种子退火终点均值，sd 1.02 |
| +混淆度 | **79.47** | 三种子；相对配对底座 +.52，2/3 为正 |
| +语境池化 / +两者 | 低于或接近底座 | 无稳定贡献 |

#### 为什么分数低

1. 当前 head 仍以局部触发词表示为主，难以区分“同一个词描述不同事件”；
2. 成对分类误差经过聚类会被放大，局部 pair-F1 并不保证 MUC 提升；
3. 已测试的上下文和混淆度机制效应小于约 1 点的种子噪声；
4. 换长上下文或更大 backbone 已经是负结果，说明缺口不主要来自容量。

#### 文献驱动的改进方向

不再继续换 encoder 或堆手工特征。下一周期采用两层结构：

1. **事件感知的度量学习**：融合 event-alone 特征、多种 pair similarity，并对“相同触发词但非共指”
   做 supervised contrastive hard negative；这一方向直接对应
   [Learning Event-aware Measures](https://aclanthology.org/2023.findings-acl.855/) 的有效机制；
2. **关系感知联合表示**：把 Ch2 的 causal/temporal/subevent 表示作为辅助信号，学习“同一事件不应同时
   出现冲突关系”的结构表征。MAVEN-ERE 原论文的 joint 优于 single，也支持这一方向；
3. **簇级训练目标**：训练时加入 antecedent/cluster consistency，避免只优化 pair-F1 却伤害 MUC。

本周只完成可运行方案和小样本 smoke；没有清晰的 hard-negative 分离增益就不启动多种子长跑。

### Ch2：事件关系抽取

#### 已完成内容

- 同协议重跑 official single、official joint 和本地成对分类器；
- 50 epoch 可比预算把 causal 从 26.31 提到 31.42，排除了“主要只是欠训”的混淆；
- 第一周期实现逐关系族工作点控制，三种子均值达到 33.27，但 temporal 护栏差 0.02，方法未过门；
- 新诊断发现跨句 causal 的 recall 只比同句低 .062，真正差距在 precision：.1998 vs .2904；
  跨句预测数是 gold 的 2.6 倍，同句为 2.0 倍；
- 逐位置诊断上限达到 causal 33.80，高于 33.17 主锚，且三族护栏可同时满足；
- 已实现逐族×逐位置的六桶训练控制器，447 tests / 16 skips、ruff 和 CPU smoke 全绿，
  代码已推送，4090 新信任根与 preflight 已通过；2 epoch GPU 行为 smoke 也已 PASS。

#### 当前指标

| 系统 | causal P/R/F1 | subevent | temporal | 判定 |
|---|---:|---:|---:|---|
| official joint | 34.37 / 32.05 / **33.17** | 29.75 | 51.63 | 主锚 |
| 本地 50ep 底座 | 22.15 / 54.02 / **31.42** | **30.62** | 50.78 | causal 低 1.75 |
| adaptive workpoint s13 | 27.03 / 42.99 / **33.19** | **33.02** | 50.38 | temporal 破线 |
| both 三种子均值 | — / — / **33.27** | **31.39** | 50.61 | 未过预注册门 |
| ProtoEM-inspired dependency s13（5090 exploratory） | 20.25 / 56.42 / **29.80** | **32.64** | **51.81** | causal 未过，整案停止 |

最后一行已用同一 internal-dev 候选全集和官方 evaluator 评分，但 5090 backbone 内容身份未闭合正式
4090 pin，所以只用于方法筛选，不进入论文正式同协议主表。完整证据和哈希只见
[`results/PHASE_A.md`](../results/PHASE_A.md)。该臂只过 subevent/temporal 护栏，未过 causal 主锚；
没有启动额外种子或超参扫描。

#### 为什么分数低

1. 无关系样本占绝大多数，逆频加权把模型推向高召回、低精度工作点；
2. 跨句候选的语义歧义更大，却与同句候选共用一个决策边界；
3. 现有全量 pair classifier 对所有 O(n²) 候选一视同仁，难负例淹没了正例；
4. 第一周期主要移动决策边界，改变排序/判别力的增益只有约 .12，小于 seed sd .82。
5. 原型依赖探索的 causal precision 仍只有 20.25、recall 56.42，说明当前低分继续来自 causal 过发；
   简化实现还缺论文的 `None` 文本原型与 event-agnostic context，不能靠扫温度或 support 数补洞。
6. ATLOP adaptive-threshold loss 的 2ep 竖片中 causal/subevent 都为 0，说明直接关闭外部类权重会被
   全量 NONE 淹没；该通用 DocRE loss 不能直接搬到当前三族设定，已停止 50ep。

#### 文献驱动的改进方向

优先级按“与本项目错误形态的匹配程度”排列：

1. **pair-specific evidence + 长文共同上下文**：让每个跨句 pair 从共同 token evidence 建模，而不是只
   拼接两个 trigger embedding；ATLOP 的 localized context pooling 是一手依据，但当前多窗口 encoder
   需先完成跨窗口 attention 重构，不能做伪适配；
2. **cluster-aware context compression**：为跨句 pair 选取相关句簇并压缩冗余，TacoERE 在
   MAVEN-ERE 上给出 causal 34.1 / subevent 30.6；
3. **关系原型与结构 rationale**：简化 prototype 已失败；下一轮若继续必须补 `None` 文本原型、
   event-agnostic context 与完整依赖图，而不是扫描 support/temperature；
4. 两阶段 retriever 的三个单种子 Stage-1 竖片均未过 recall 门，暂时降级；六桶 controller 的完整
   seed13 已在 4090 启动，但服务器入口不可达，恢复后只核既有 official 结果，不重启或加 seed。

截至 8 月 31 日，行为验证已经通过：训练器 internal-dev macro .3178 → .3328，六桶最终 offset
介于 −.536 与 +.328，完整 12 条轨迹无发散；causal 跨句桶的门槛方向符合“跨句过发”诊断。
这一步没有运行 official evaluator，因此不是新的论文主表分数，只说明可以进入完整 seed-13。

### Ch3：事件事实性检测

#### 已完成内容

- 建立五类标签检测、支持证据 span 检测和配对 bootstrap；
- 同协议重跑 RoBERTa+CLS 与 DMRoBERTa；
- 实现 evidence→label 软耦合和等宽度 uniform 容量对照；
- 发现 internal-dev 只有 PS− 19 个、Uu 14 个，五个系统在 Uu 上几乎全部为零；
- 证据轴有 1,276 个 gold span，是决定 macro-F1 的稀有类实例数的约 18 倍。

#### 当前指标

| 系统 | 五类 macro-F1 | PS− F1 | Uu F1 |
|---|---:|---:|---:|
| evidence（我们） | **.5554** | **.500** | .000 |
| RoBERTa+CLS | .5458 | .483 | .000 |
| DMRoBERTa | .5423 | .476 | .000 |
| uniform 容量对照 | .5292 | .400 | .000 |
| none 底座 | .5283 | .350 | .061 |

evidence 相对 RoBERTa+CLS 的 Δ=.0096，95% CI [−.0398, +.0630]；相对 DMRoBERTa 的
Δ=.0131，95% CI [−.0250, +.0522]。因此只能写“点估计更高、统计上不可区分”。
证据轴上，我们的 evidence macro 为 .5511、pooled span F1 为 .4521，均高于平行双头。

#### 为什么分数不稳定

1. CT+ 有 6,835 个实例，而 PS−/Uu 合计只有 33 个，macro-F1 被极少量实例支配；
2. 当前 split 的配对 MDE 约 +.051，大于我们观察到的 +.01～.03；
3. 现有证据耦合改善了 CT−/PS−，但没有解决 Uu；
4. 单纯增加标签头容量几乎无效，说明增益来自证据信号，但标签空间仍缺少语义结构。

#### 文献驱动的改进方向

1. **保留 evidence-conditioned 主干**，把证据定位从附属任务提升为共享表征的核心；MAVEN-FACT
   原论文也显示 supporting evidence 本身困难且有独立信息；
2. **标签描述/原型对比学习**：用 CT+/PS+/CT−/PS−/Uu 的 polarity×modality 定义构造原型，
   对稀有类做 supervised contrastive 或 logit-adjusted class-balanced loss；
3. **分层判别与文档推理**：先 factual vs non-factual，再判 certainty/polarity，并把证据 span 作为
   句到文档的推理中介；已有工作分别用
   [MRC+transfer](https://aclanthology.org/2022.coling-1.231/) 和
   [sentence-to-document inference](https://aclanthology.org/2023.findings-acl.879/) 缓解文档级样本稀缺；
4. **加入事件论元和关系辅助**：MAVEN-FACT 原论文实测这些信息能帮助 fine-tuned 模型；必须设
   同容量对照，防止把参数增加误当机制增益。
