# 重规划材料索引（历史研究依据）

本目录保存 v6 定案前的文献检索、数据资格审计和方向论证。它们只能解释“为什么形成当前设计”，
不能作为实验任务、当前状态或结果数字的来源。

使用顺序：

1. 当前设计与验收规则只读 [`../SPEC.md`](../SPEC.md)；
2. 当前状态与下一步只读 [`../HANDOFF.md`](../HANDOFF.md) 和 [`../TODO.md`](../TODO.md)；
3. 需要追查方向决策时，先读 `SYNTHESIS_DECISION.md` 和对应的 `*_audit.md`；
4. 无 `_audit` 后缀的网页研究导出只是输入材料，不能替代一手来源复核；
5. 本目录中的 PDF 是本地导出副本，不是 Git 事实源。

一次性网页提示词和重审过程 HANDOFF 已从活动树移除，取回位置见
[`../ARCHIVE_INDEX.md`](../ARCHIVE_INDEX.md)。
