## 7. 方法贡献数量

**2 个自提模型**：

1. **KPEE**（第 3 章）：基于知识提示微调的事件抽取（知识注入提示 K(X) + 提示编码器 Prompt encoder + BART 条件生成 + 槽位映射）。
2. **GM-ECR**（第 4 章）：门控机制融合多层次信息的事件共指消解（全局提及编码器 + 局部提及编码器 + 事件成对表示 + 门控过滤 + 共指判别）。

§1.3「主要工作和创新点」（L400–L424）列 **3 条**，第 (3) 条是「问答系统设计」（Flask 前后端 + 图谱 + 问答解析），属工程实现；「结论」（L1885–L1905）同样列 3 条，第 (3) 条为事件知识图谱构建。即 **2 个方法 + 1 个系统**。

两个模型是**串行依赖**的：第 4 章明写「首先利用第三章中抽取的事件结构来获取论元的位置信息」（L1895），门控模块的立论就是「降低事件抽取步骤的论元抽取**传播误差**」——这构成了两章之间的真实技术链路，而不仅是并列。
