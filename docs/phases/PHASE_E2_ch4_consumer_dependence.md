## 0. 立论：一个与 ACL 2025 的正面实证冲突

| | Koupaee et al., **ACL 2025**（CGEL） | **我们**（Phase E） |
|---|---|---|
| 消费者 | **in-context LLM**（GPT-4o / Llama-70B，**不微调**） | **微调** SeDGPL（10 epoch） |
| 图的角色 | 推理基底（答案＝查询事件能否作叶节点插入图中） | ≤20 条边的 prompt 模板，模型**同时看得到事件文本** |
| 结论 | **更好的图 → 下游大涨**（叙事完形 13.0→**55.0**；含上下文 38.0→**61.0**） | **更好的图 → 零变化**（六种干预全在噪声地板 ±.003–.004 内） |

我们的零**不是没调好**，是构造性的：净化用**金标 oracle 标签**仍 −.0000（p=.97）、
`repaired_nobreak` 与 `predicted` **逐位相同**、修复对上等量随机删边强对照 p=.60。

**★ 可检验的解释（本 phase 要验的假设）**：
> 图质量的下游收益**依赖消费者如何使用图**。微调消费者会在训练中学会绕过图噪声，
> 使图侧改进不可见；in-context 消费者直接依赖图结构，改进可见。

**这是假设不是结论。** 写作时在验完之前一律用「假设/待验」措辞。

## 执行内容（Steps）

### 1. 先证明 in-context 臂是可信实现（不做这步后面全白跑）

在**未扰动的 gold 图**上复现出「**有图 ≫ 无图**」的大间距。CGEL 的 Table 6 是
one-shot 13.0 → CGEL 55.0（含上下文 38.0 → 61.0）——**如果我们的 in-context 臂做不出这个量级的
间距，说明实现有问题，不能拿它去论证「消费者敏感」。**

⚠️ **可比性边界**：CGEL 用 GPT-4o，我们受 5090 单卡限制只能上 **7–14B**（Qwen2.5 / Llama3 系）。
⇒ **绝不与 CGEL 的 55.0/61.0 直接相减**。对标目标是三个**同量级的微调事件语言模型**：
**ELM 46.0 / QGELM 46.0 / EGELM 50.0**。

### 2. 同一批图 × 两类消费者

把 Phase E 已有的档位（gold / predicted / repaired / purified / purified_oracle /
random_drop_matched + 受控扰动曲线）**原样**喂给 in-context 臂。
🛑 **必须沿用 canonical 模板序**——`PHASE_E.md` 实测纯重新序列化能造出 p=.02 的假效应。

### 3. 两臂并列报，并测 in-context 臂自己的噪声地板

in-context 臂的噪声来源与微调臂不同（采样温度、prompt 顺序）。**必须独立测它的地板**，
不能套用微调臂的 ±.003–.004。地板没测出来之前，任何 Δ 都不作正面主张。

### 4. 内在评测（CRAB，可选但推荐）

CRAB（~2.7k 因果对，新闻域）是 CGEL 的内在评测集，给的是「图质量」本身的分。
接上它可以把「图质量 → 下游」两端都量化，而不是只有下游端。
