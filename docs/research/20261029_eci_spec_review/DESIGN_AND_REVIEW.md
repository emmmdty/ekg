## 1. 共用基干与输入约束

输入是原文token/句界、给定mention span和原生候选全集。复用原公开文本编码器，
得到token表示H，再按其span/pair scorer形成事件表示h_i和事件对表示p_ij，
基础分类输出z_ij∈R^C。C由语料原生label vocabulary决定，不根据结果选类别。
编码器/打包改变必须有匹配基础控制，不能把上下文窗口变长直接当机制增益。

比较方法A/B时使用同一个已恢复、有效的共同强基干。对手原生不同backbone另列
配置与预算；普通分类、目标重加权/辅助监督等强替代必须匹配比较。

## 2. 方法A：文本条件的两腿联合交互

### 2.1 所解决的问题与证据范围

待验证的问题是：同时预测同一见证事件w涉及的两条关系，有没有超出单边边缘、
普通联合分类或额外监督的有效信息。不能先断言“基线无法理解语境”，也不能把
chain/fork/collider当成必然蕴含目标边。原MAVEN动机及已否决模板沿用R122。

### 2.2 网络计算

1. **原绝对判别通路**：H→h_i/h_j→p_ij→z_ij，完整文本和NONE校准始终保留。
2. **联合头J**：对distinct(i,w,j)的两条pair表示a、b，
   `Q=softmax(MLP([a;b;a⊙b]))`，reshape为C×C。
   用原train两条可识别关系的标签作联合CE；无标签腿不伪造监督。
3. **交互读出D**：`P=Q_row⊗Q_col`，`D=Q−P`。
   每个目标类别c有兼容矩阵K_c，`δ_c=mean_w <D,K_c>`，`z'_ij=z_ij+δ`。
   K必须有真正行列交互自由度，纯a+b读出会消掉D，不能作为实现。
4. 联合loss按document内合法三元组归一化，与基础原生loss合并。aux比例、Q头
   容量、初始化和endpoint尚未冻结，均属**准入阻断**，不是留给结果后的调参空间。

有向MAVEN下原四方向模式保持；对称二类ESC/CTB不能假装方向仍可识别，
必须在正式设计中证明二类C×C的同一交互问题成立并消除重复模式。
没有第三mention时修正为空和0，原候选仍由z预测；这只是定义，不是捏造结构证据。

### 2.3 消融和竞争解释

| 比较 | 保持什么 | 改变什么 | 能回答的问题 |
|---|---|---|---|
| D vs product | 相同Q监督、参数预算、基干、训练 | 读Q的交互残差或边缘乘积 | 是否只是单边关系信息 |
| D vs full-Q | 同上 | Q完整读出或只读D | 是否普通联合结构已足够 |
| D vs aux-only | 同Q辅助监督、完整原分类通路 | 修正是否接入输出 | 是否额外辅助任务解释收益；披露有效梯度/容量不完全相同 |
| D vs attachment-shuffle | document内修正总量、训练/推理规则 | 修正归属到哪个target pair | 目标归属是否有关；不单独证明协方差机制 |
| D vs strongest base/control | 协议与适用匹配预算 | 完整候选方法干预 | 公共主指标是否真正有净收益 |

不能仅打乱同一target内部w：均值对此不变。负控必须记录实际被改变比例，
不能把同量但无效置换当证伪。三元量的数量不等于统计功效，更不等于新颖性。

### 2.4 可行性与明确否决条件

数据前提在发布ESC/CTB train上部分成立，但联合正例、标签方向与比例差异很大。
MAVEN已完成的R120人口不重做。各语料须先做C×C监督与功效检查；旧单删FP power
不能给这个可能同时改TP/FP的候选背书。

复杂度为O(sum_doc n³C²)，仅分块降低驻留内存、不消除计算量。
不以随机丢NONE/候选或gold coref去重规避预算；如完整版本实际不可行，则点名
【算力/协议】并停止这个版本，不在实现中偷偷采样。

若机制只是已知联合head/概率结构移轴、二类退化后无独立问题、最强full-Q解释收益、
或原生主指标/护栏失败，拒绝固定候选，不通过改名、换seed或扫aux scale挽救。

## 3. 方法B：真实预测误差下的结构修正

### 3.1 所解决的问题

研究对象是“训练图/修正训练输入比部署图更干净”及预测结构中的误报与漏检，
不是再次提出普通图attention或迭代推理。UCGraph、PPAT、SVRECI及真实denoising/
exposure-bias近邻必须逐项比较；当前**具体增量与效果尚未证明**。允许有意义的小改进，
不要求独立算法家族；OOF等已知构件本身不报创新。

### 3.2 可检验的架构草案

1. **冻结初始预测器F**：原文/mentions→z,p；基础版本不依赖A，保证B可单独成立。
2. **误差暴露输入**：在外层训练人口内部作cross-fit，每条训练图边来自未用该文档
   标签训练/选模的F。保留完整候选概率，包括误报边和漏检边，不把gold图当部署图。
3. **局部纠错网络G的具体待审版本**：每个有序target pair是一节点；邻域只取同文档
   共享endpoint的pair，保留其方向标记；无向协议则显式合并重复方向。对邻居e取
   `x_e=[p_e;softmax(z_e)]`，`a_e=softmax_e((W_q p_ij)^T W_k x_e/sqrt(d))`，
   `m_ij=sum_e a_e W_v x_e`。一次消息读出后，
   `g_ij=sigmoid(w_g^T[p_ij;m_ij;softmax(z_ij)])`，
   `Δ_ij=W_c[p_ij;m_ij]`，`z'_ij=z_ij+g_ij Δ_ij`。
   不做硬边筛选、pattern蕴含或迭代扩边；无邻居时m为空和0，候选仍保留。
   计划复用真实公开pair-attention实现的相关层/接口，适配差异必须记录，不能把
   普通attention本身报创新。
4. 监督只用外层train关系标签。外层dev/test的标签不进入G、校准或图构造；
   cross-fit的内层selection也不能借外层dev。输出仍覆盖原始完整候选。
   候选编辑门标签为`u_ij=1[argmax(z_ij)≠y_ij]`，只在训练时由OOF预测和训练gold
   生成；目标为`CE(y,z')+λ_gate BCE(u,g)`，document内归一化。匹配的无结构编辑
   控制也接受同一u监督，排除增加正确性辅助标签的解释。λ_gate、容量/初始化和
   正式endpoint仍未冻结，均为签发前阻断；不能留给看过dev以后选择。

上述给出了可以审查张量、监督及消融的计算版本，但尚非最终网络规范。如果具体改动
没有必要性/可归因收益，只是已有普通graph-refiner/阈值校准或原R122的另一种写法，
就不作为第二方法贡献；不以“加一个loss”本身裁定充分或不充分。
研究价值待检验真实错误输入与显式错误监督编辑的作用；一次更新、少一个模块若有
具体问题与公共主指标证据也可作改进，名称/数量本身不算证据。dense邻域的总体开销仍可能为O(sum n³)，要实测，
不能凭“轻量纠错”四字免除成本门。

### 3.3 必需的比较

| 干预 | 最强对照 | 要排除的解释 |
|---|---|---|
| 真实OOF错误输入 | 同容量的gold随机删/增边噪声训练 | 是否只要普通denoising，不需要真实预测误差 |
| 显式误差/编辑通路 | 参数/监督匹配的普通结构修正器 | 是否只是增加容量/监督 |
| 错误监督的编辑门 | 去掉错误辅助目标的同结构门；同错误监督的无结构编辑器 | 具体门控是否有必要，是否只需普通二阶段分类 |
| 条件修正 | 温度校准、固定合法阈值策略或同预算置信度控制 | 是否只是输出更保守；所有策略只能dev选择 |
| 正确配准的预测结构 | 语义可解释且有效的归属/结构负控 | 结构内容是否真的参与决策；负控效力须检查 |
| B-only | 共同强基干和公共强对手 | B能否独立形成方法贡献 |
| A+B | A-only、B-only及base | 两者是否互补，而非一章重复另一章 |

oracle clean graph只作明确诊断，不进入可部署主表。A+B若在A输出上重新拟合B，
必须对A的训练输入再次遵守内层OOF，不能直接拿in-sample A图当deployment代理。
报告新增TP/丢失TP/新增FP/消除FP及错subtype，不能只报“误报少了”。
