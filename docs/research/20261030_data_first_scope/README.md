## 3. 为什么能拆成递进研究，而不是先凑三个模块

相关论文已经把CDCR处理过程分为召回、事件对判别和聚类；EasyECR正文与实验又
分别检验了这些环节，并说明固定其他环节的重要性。具体问题、对手与完整主结果
要求见[递进框架与协议提案](THESIS_FRAMEWORK.md)。

这给出了三个有公开研究基础的问题位，**尚未证明某个新模块有效或足够新颖**。
每章仍须基于训练/开发证据定位其特定错误、核直接近邻并提出可区分的改进；不能
把公共pipeline原样拆成三章，也不能把三个普通模块直接当三项贡献。
