# CDCR三方法章：指标与比较规范

2026-10-30，前瞻规范v0.1；同C41-A-R/T087研究准备切片。适用给定事件提及的
跨文档事件共指，不扩展为事件检测、关系抽取或完整事件图谱。本文规定如何评价，
不启动模型实现、复现或训练，不改写旧MAVEN冻结协议。作者要求原论文有可查成绩
即可收录，代码不作门槛。成绩唯一权威为[R1 §25.153](../../results/PHASE_R1.md)，
逐表入口为[九表导航](NINE_TABLES.md)。

## 1. 共同结果组与判定顺序

| 层级 | 每个语料、每个完整系统必须报告 | 用途与判定 |
|---|---|---|
| 共同主指标 | CoNLL F1 | 最终身份归并的主要比较依据；三个语料分别报告 |
| 标准分项 | MUC、B³、CEAFₑ各自P/R/F1 | 展示主分由哪些部分构成；不能挑较好的一项代替主分 |
| 共同补充 | LEA P/R/F1 | 补充链接与簇重要性视角；不与CoNLL再平均成自造总分 |
| 章节诊断 | 第3节对应的召回、精判或聚类错误指标 | 验证该章声称解决的问题；局部提高不自动等于最终任务提高 |
| 代价 | 第5节的时间、调用量、token与显存 | 解释质量改善的资源代价，不把其他论文异硬件耗时排成名次 |

CoNLL F1 = (MUC F1 + B³ F1 + CEAFₑ F1)/3。先用未四舍五入的各项F1求均值，
最后显示；不是先平均P/R再求F1，也不制造CoNLL P/R。统一保留机器原始精度，
论文显示精度一致，差值用百分点。各语料完整评分后报告，禁止按batch、文档或
主题简单平均出另一个“CoNLL”。

采用[参考评分实现论文](https://aclanthology.org/P14-2006/)及已核的
[Reference Coreference Scorer v8.01](https://github.com/conll/reference-coreference-scorers/tree/f49f3f8a0e1cdc5ceba7c2a33013897369df5543)
作MUC/B³/CEAFₑ实现锚；LEA遵循
[Moosavi与Strube的定义](https://aclanthology.org/P16-1060/)。LEA实现及单例规则要在
同一评分入口记录revision并以规范例检查，不能将三个标准指标交给不同的默认
过滤器。这里没有声称已完成新框架评分程序的运行验证。

结论分开写：主分提高支持完整系统改善；局部诊断改善支持相应机制；主分下降而
诊断提高只能说明局部权衡。分项有升有降须展示，不增设“全部分项都涨”的武断
门槛。文献原分是外部锚定，不冒充本项目统一运行结果；不要求不同任务的数值都
达到同一个百分数。多个语料不得平均后掩盖某一语料退化。

## 2. 所有章共用的计分人口

- 使用已核公开原划分：ECB+按发布的句子过滤；GVC按原incident membership；
  WEC-Eng使用原train与命名的人工验证dev/test。数据身份见
  [来源与框架](THESIS_FRAMEWORK.md)。不跨章重抽split，不把GVC簇ID或主题当输入。
- 主任务人口为该split全部给定提及M，包括单例；每条输出必须恰好出现一次。
  缺ID、额外ID、重复归属或跨split读取均使该次评分无效，不能丢掉后继续报分。
- 推理不借助gold topic、subtopic、incident、事件簇或其他gold语义属性阻断。
  候选检索可在完整split人口上无监督地建索引，但只用许可文本与提及坐标。
- 同一语料的完整test作为一个跨文档评价分区，mention ID全局唯一；原文档和词位
  映射保留，跨文档同指不被文档边界截断。评价包括文内及跨文档身份连接；跨文档
  局部pair诊断另列。固定分区后，各系统共用同一gold与scorer调用方式。
- 主报告保留全部给定单例。附加“去gold单例人口”报告：只在评分时选出gold簇大小
  大于一的固定提及子集，把gold及每个预测簇都投影到该子集，删空簇，保留投影后
  的预测单例。它与主表分开，明确写成gold非单例人口子集；不与原论文未说明的
  “no singleton”数值直接混排。不按系统预测对错改变该子集。
- 阈值、k、提示词、生成长度、停止条件与模型选择只用train/dev。测试标签只用于
  冻结方案后的评分和预定误差统计；不得用于候选选择、提示修订或事后选主指标。

下文U是M上所有不同提及的无序对集合，G是gold同簇的无序正对集合，均包括文内和
跨文档对；U_cross只保留不同文档的对。对计数可由簇大小/交集大小组合计算，不
要求枚举整张二次方矩阵。下列诊断比例分母为零时记NA并报告人口；标准指标保留
参考scorer本身的约定。pair F1直接以2TP/(2TP+FP+FN)计算：没有正预测但存在正标注
时为零，三项全零时为NA；不因P无定义而隐去已有漏判的F1。

## 3. 各章的辅助指标、分母和受控比较

### 第3章：候选覆盖

问题：词面差异导致真正同一事件的提及未进入后续精判。参考
[DCT](https://aclanthology.org/2021.emnlp-main.106/)、
[LemmaECR](https://aclanthology.org/2023.findings-acl.100/)的候选阶段；以下公式是
本项目事前规定的诊断口径，不冒称这些论文均发表过相同数值。

每个提及查询k个不同近邻，排除自身，以相似度降序、同分按mention ID确定顺序。
有向列表N_k(m)取无向并集得到去重候选C_k；两端都检索到的pair只记一次。

| 指标 | 定义/分母 | 解释 |
|---|---|---|
| Candidate-pair Recall@k（micro） | \|C_k∩G\|/\|G\| | 完整正对中有多少进入精判；分母不先限于已检索结果 |
| Mention Recall@k（macro） | 对所有非单例提及m，平均\|N_k(m)∩(gold(m)−{m})\|/(\|gold(m)\|−1) | 每个有同伴提及的完整同伴覆盖率；按提及平均 |
| Mention Hit@k | 同一非单例提及人口中，至少召回一个真同伴的比例 | 与Recall@k分开，不能把“找到一个”称为找全 |
| 候选量与压缩率 | 去重\|C_k\|，以及1−\|C_k\|/\|U\| | 说明送入pair模型的真实预算，不只列有向查询k |
| 跨文档候选召回 | \|C_k∩G∩U_cross\|/\|G∩U_cross\| | 排除大量文内正对可能遮蔽的跨文档漏召回 |

固定同一pair scorer与decoder，比较原召回、lemma、同预算语义检索与本章召回，
每项都输出完整CoNLL结果。k及模型只由dev选定，并报告共同k和实际去重pair量；
若候选量不同，用相同去重pair预算的对照或质量—预算曲线解释，不能只称“同k”
就视作同成本。检索曲线的k网格事前记录，不从test曲线挑最优单点。

Candidate-pair Recall不是最终CoNLL的数学上界：部分边可经传递连接成簇。候选
诊断提高仍须看完整聚类分数；不给“漏掉一个pair就必定无法同簇”的错误推论。

### 第4章：语义精判

问题：相似表达的不同事件容易误判，差异表达的同一事件容易漏判。参考
[SECURE](https://aclanthology.org/2024.acl-long.164/)、
[ROEC/CKD](https://aclanthology.org/2024.naacl-long.218/)、
[LLM-RCDA](https://aclanthology.org/2024.naacl-long.63/)的语义辅助/监督。

固定同一去重候选集合C及其hash，所有判别器评价C的全部pair，测试时不采样负例。
正例为C∩G；给定冻结阈值后的正预测集合为S⊆C。

| 指标 | 定义/分母 | 解释 |
|---|---|---|
| Candidate-conditioned Pair P | \|S∩G\|/\|S\| | 仅在共同候选上的正类精确率 |
| Candidate-conditioned Pair R | \|S∩G\|/\|C∩G\| | 候选已经存在时的正类召回率；不含未检索正对 |
| Candidate-conditioned Pair F1 | 2TP/(2TP+FP+FN)，非退化时等于上述P/R调和均值 | 只表示pair判别，不等于最终簇的Pairwise F1 |
| 同lemma负对FPR | 同lemma且gold不同簇中，误判为正的对数/该负对数 | 针对词面相近的误合并风险 |
| 异lemma正对FNR | 不同lemma且gold同簇中，误判为负的对数/该正对数 | 针对差异表述的漏判 |

lemma规范器/版本与大小写规则跨模型固定；只把它作为词面分组代理，不宣称自动
识别了全部语义难例。四个“同/异lemma×gold正/负”格都列样本量，若为空记NA。
未检索到的正对由第3章完整G上的召回以及完整系统结果反映，不藏进条件pair R。

对照包括相同encoder/输入预算的原判别器、去语义辅助、去本章核心模块，以及
同一开放LLM的直接pair判断；训练资源、公开原分与透明适配分别记载。LLM输出
非法格式率以全部请求为分母，额外/缺失ID单列；超长截断和失败不能静默丢样本。
不新增人工事实标注任务，不把格式正确率包装成事实真实性指标。

### 第5章：簇级归并

问题：pair局部错误经错误桥接放大，过严阻断又拆散同一事件。参考
[WEC的聚类](https://aclanthology.org/2021.naacl-main.198/)、
[DCT](https://aclanthology.org/2021.emnlp-main.106/)、
[SECURE的合并检查](https://aclanthology.org/2024.acl-long.164/)与
[CohTP](https://aclanthology.org/2026.acl-long.1345/)的全局机制。

冻结同一候选seed、pair scorer函数及已有边分数。各归并器若需要查询额外pair，
必须共用可查询全集/规则与预算，新增查询计入成本；未知分数不当零、不当负例。
比较CC、适用的single/average/complete-link、SECURE式merge-check与本章方法。

设完整预测分区产生的全部同簇对为P（包括未显式查询、经传递得到的对）。

| 指标 | 定义/分母 | 解释 |
|---|---|---|
| Partition Pairwise P/R/F1 | Precision=\|P∩G\|/\|P\|，Recall=\|P∩G\|/\|G\|及2TP/(2TP+FP+FN) | 全提及分区上的链接质量；与第4章候选条件F1分开命名 |
| 误合并pair数FP / 漏合并pair数FN | \|P−G\| / \|G−P\| | 报原计数及分母，解释桥接与拆散代价 |
| 预测簇不纯率 | 交叠多个gold簇的预测非单例簇数/预测非单例簇数 | 预测簇视角错误分析；列分子/分母 |
| gold簇碎裂率 | 分散在多个预测簇的gold非单例簇数/gold非单例簇数 | 真实事件视角错误分析；列分子/分母 |

LEA与CoNLL分项仍共同报告。上表后两项属于本项目明确规定的误差统计，不取代
公开主指标，不伪称论文同口径已发表成绩。合法分区天然满足传递性，“传递冲突
为零”不能作为优于其他合法聚类方法的证据。全ID覆盖也是有效性检查，不是创新。

## 4. 每章的表格和消融交付

每章三套数据表使用相同主表列：方法、输入/设定标记、MUC F1、B³ F1、CEAFₑ F1、
CoNLL F1、LEA F1；P/R/F1长表另附。原论文缺少的格写“—”，标明未报；本项目
未来输出不得以“原文没报”为由省掉已规定可算的标准组。

每章另有诊断表、消融表、成本表和误差分组表。消融包括完整方法、去该章核心
模块、同预算常规替代、匹配的负控；模块名字/网络实现由后续方法设计确定，不能
现在编造一个尚未定义的网络。每个消融同时列完整CoNLL和对应局部诊断。

归因链固定为公共共同pipeline→替换召回→再替换精判→再替换归并；另在共同
pipeline分别单独替换有独立定义的模块。第4章固定候选，第5章固定pair scorer；
累计改进与本章独立贡献分开报告，不把换encoder、加候选或加查询的收益归给另一
模块。没有独立定义的机制明确写依赖，而不是强造独立消融。

当前九表为文献原条件成绩，原文均值/单次、LLM、oracle、encoder、split、分区
和单例处理差异随行保存。某论文未明确说明的字段记“未核到”，不能默认一致。
CD-DCE原表算术异常见结果页†；不自行修正，也不作为唯一达标数字。

## 5. 成本、选择和报告契约

成本至少记录：语料规模、唯一候选数、pair前向总量、LLM请求数及输入/输出token、
检索/语义辅助/精判/归并/总墙钟时间、峰值显存；同时记机器、batch、精度、上下文
和并发方式。峰值显存只在同条件下比较；不把论文异硬件耗时直接排名。

LLM文本提前生成时，冷启动完整成本与缓存后成本分开；离线生成计入总成本，
缓存命中率/生成配置/缓存身份保存。不以缓存推理的时间冒充整个方法成本。
同一系统的质量和成本必须来自同一配置，不能拼最高质量和最低成本两个版本。

每份结果同时携带dataset/split/mention ID及候选hash、gold人口、scorer revision/
命令、主/附加单例规则、评价分区、输入权限、checkpoint/prompt身份、开发集
选模规则、seed与commit。文献表保存论文/PDF哈希和Table/页/变体。
已有单seed/机器授权不在本规范内扩张；不临时增加多seed或统计显著性硬门。
