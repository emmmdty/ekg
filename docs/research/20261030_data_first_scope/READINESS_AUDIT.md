## 3. 数据与可比性：本次实质修正

此前对GVC的“标签0跨split”只作重叠披露，不足以解释其标注含义。
[Bugert等2021，附录D](https://aclanthology.org/2021.cl-3.18/)明确说明该桶涉及泛指
事件或未解决的跨子主题链接，并在其设置中删除；作者loader有`drop_0_cluster`。
[uCDCR2026，§7.1.6](https://www.lrec-conf.org/proceedings/lrec2026/pdf/2026.lrec2026-1.328.pdf)
则将这些提及分别单例化。SECURE的公开GVC reader传递原始标签，未执行该删除。
这些是不同公开约定，不能说它们仅共享划分就有同一gold分区。

**本框架前瞻处理**：原始文件不改、原论文数字不改。GVC原人口/原标签的native
结果保留，明确包含特殊桶；同时对同一批完整预测作固定非0提及投影，重算完整
CoNLL、LEA及分项，并列全部控制/消融。该视图沿用已发表的排除规则，不加人工
标注，不新造现实事件ID，不增加一轮模型训练。它不能与包含0的原分直接排名。
簇0不支撑“归并了同一现实事件”的案例或机制论断；不能只凭该桶带来的涨分作
实体身份技术改善的结论。暂不切换成uCDCR版数据，避免同时引入重分词和修订标签。

原件人口、0桶人口与非0投影人口只见结果页。GVC原划分应准确称为“采用Bugert等
已发表公开incident划分”，不再写成数据创建者提供的唯一官方划分。

另一个区别是评分器：SECURE原实现明确包含单例并有自己的LEA/CEAF函数；本文
采用的官方参考评分实现不能仅凭指标同名就与其等价。论文原分表保留native身份，
后续项目统一控制表必须共用同一评分入口。作者要求本轮暂不复现，这不妨碍先
固定比较条件，也不等于以后能省掉机制归因所需的共同控制输出。

## 4. 公共对照包与比较表的用途

| 公共包 | 覆盖 | 用途与名称边界 |
|---|---|---|
| B0：DCT式原文共同pipeline | 三语料 | 学习式检索＋cross-encoder＋已有归并；ECB+/GVC引用原实现，WEC用已有多语料接口透明适配；不虚构DCT原论文的WEC成绩 |
| B1：SECURE式语义辅助pipeline | 三语料 | 统一开放teacher和相同encoder/预算的透明适配，对照LLM辅助；不能称为原GPT-4版本的精确复现 |
| H：lemma/训练集lemma同义控制 | 三语料 | 简单已发表机制，统计只来自train；不使用gold主题过滤或测试簇构造字典 |
| W：WEC作者原系统 | WEC-Eng，原文另有ECB+ | 保留作者pair模型＋average-link的原任务锚；不把它当本章每层独立贡献的分数 |

文献对照范围仍包括九表全部已发表方法，不受这个最小执行包限制；CD-DCE/CohTP等
没有公开实现也继续收录。当前没有跑B0/B1/H/W，不填我方成绩或FR-016复现通过。

第3章在固定B0精判/归并下比较召回；第4章在固定候选/归并下比较原文、LLM辅助和
自有精判；第5章固定pair评分函数、seed候选与查询权限，比较CC、适用的linkage、
DCT/SECURE合并检查与自有decoder。各章同时列完整主指标和本章诊断。

三类结果必须清楚命名：原论文条件成绩用于定位；本项目统一控制表用于直接归因；
必要的native兼容/敏感性表用于解释口径。不得把未对齐的原分和本项目新分混成一个
未加说明的排行榜。这是比较设计要求，不是要求当前提前复现所有已发表模型。

第5章末尾嵌入面向事件节点库的工程验证：同一公开语料上的完整pipeline、系统对照、
输出全ID与证据回查、成本/图规模分层和失败案例。输出簇及其提及证据可形成规范化
事件节点；本论文不因此声称已完成因果/时间关系图或自动事件检测，不用画图充当
第四项创新。公开身份分区指标仍是主任务评价，不复制成一个虚假的新应用分数。

三个方法章各自需要问题分析、相关方法局限、数学/网络/推理设计、公开主比较、
消融、诊断、成本和失败边界，具备不同技术内容时可支撑篇幅。当前没有学校规定
“必须三个方法章”的证据；工程类专硕的工程背景与验证要求不因三方法章而免除。
这一结构建议与此前针对旧ECI路线的两方法＋工程章建议适用对象不同。

## 6. 进入下一阶段前还要交付什么

先完成新项目范围spec和公共实验配置，落实reader/评分器/比较包的确定入口；再
逐章写可编码方法设计，然后实现与迭代。三章设计至少必须交待输入特征、网络/
推理步骤、训练目标、推理可得信息、最接近方法的具体差异、强替代、模块消融与
完整评价输出。不要先写一个网络再反找它要解决的问题。

这不是继续等待新数据/私有代码，而是把已有公开条件接成能执行的研究。当前可
认为选题与实验骨架已成立；不能把“自有方法具体设计、公共接线、运行验收”三件
尚未完成的工作缩写成“只剩调优”，也不承诺以文档审查保证未来没有任何技术变更。
