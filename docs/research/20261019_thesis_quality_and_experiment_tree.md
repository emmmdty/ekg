## 如何把“优于”落到本项目

| 质量维度 | 我们最终应拿出的证据 | 当前差距 |
|---|---|---|
| 问题与方法贡献 | 强对照的真实残余错误、可用信号、最近邻机制的实质差异、可证伪预测 | 诊断不少，三个方向均未兑现新方法的正向贡献；泛泛加图/对比学习不足以立项 |
| 主结果竞争力 | 各方法在自身统一公开主指标上胜过多个适用强对手；适配保真度/输入差异透明，包含当前直接机制邻居 | 不能用旧论文弱baseline撑胜出；ERGO尚无完整训练结果，其他方法也未胜其强控制 |
| 实验设计与归因 | 同协议、同backbone必要控制、单变量核心消融、简单替代解释、负控与次任务护栏 | 已有大量负证据可复核；尚缺“正增益确实来自所提新机制”的证据链 |
| 泛化与稳健性 | 在既有MAVEN任务、分折/合法留出和预定错误层次报告收益边界；合法确认及配对不确定性随结论交付 | 单seed探索不等于稳定优势；不因参考论文用了多数据集/多seed就擅自加任务或解封final-valid |
| 应用与范围 | 真实图构建、消费者公开对手、图依赖/扰动、可复现输入身份；结论对应实际上游 | E3首轮已有较完整证据，但上游是v5；不能把它当当前三个方法的下游收益 |
| 可复核性 | 主表反查源码、命令、配置、checkpoint、全量预测与官方scorer；不在测试/封存集调模型 | 已有较好基础；可追溯不能替代主结果，整体“已超过四篇”的结论仍不成立 |

多数据集能增强外部泛化，但不是从四篇取并集后强加的新门；我们既有任务的深入对照与
有效性是眼前必须兑现的内容。若最终确需扩数据或改变论文结构，先按主表与作者权限处理。
不设虚构的综合质量分，不保证毕业/答辩结论，不为追大幅提升牺牲有效性。

## 分数卡点与下一行动

详细数值和归因边界认[R1 §25.118/§25.120](../results/PHASE_R1.md)。目前可支持的工作判断是：

- D4：强linear能拟合大量训练样本，输入完全截断不是主要人口；优先找稀有类泛化的
  可识别监督与推理可用信号。支持缺失不能伪造为scope负例，泛泛证据attention不是新方法。
- A4：旧残缺证据流的训练损伤已确证，不能靠推理阈值恢复；强锚有较强训练拟合能力，
  泛化原因尚不能唯一归因。先完成当前ERGO强rival的既定成本/完整预算决策，再依据同协议
  误差差异选择干预；公开工作已覆盖渐进图推理和迭代图更新，不能把这些名称当创新。
- C5：固定新结构目标改变错并与漏并的权衡，未增添足够身份判别信号；仅抑制合并、
  优化辅助pair指标或胜过shuffle不足以达成主指标目标。候选需同时预测能修哪些错并/漏并，
  与类型强控制及简单结构rival区分，而非继续调固定exact家族。

这是候选筛选依据，不是已准入的新模型或保证涨分的配方。科研瓶颈是**找到可泛化的新
判别信号，并证明训练干预能把它变成主指标收益**。算力限制阻断当前成本实验，但不能
解释之前所有方法为何失败；添装AI框架也不能替代这一步。
