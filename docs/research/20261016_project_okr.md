数据与power缺口。资源恢复只解除机器不可达，不能视为方法准入或指标可达证明。

## 从KR拆到最小可判别实验

统一流程：**最近邻与残余错误 → 可用训练信号 → 可证伪设计 → 成本/合同 →
完整同协议实验 → 独立复算与归因 → 准入后确认**。独立采样/统计单位为文档，
mention、pair、fold不是额外独立重复。五折OOF必须合并预测后计分。

| 研究 | 唯一拟议变化与主要竞争解释 | 必须回答的问题 / 停止条件 |
|---|---|---|
| C5 exact joint | 同parent模型、first-dummy规范目标、pair surrogate及scale/decoder不变；五臂corrected marginal / root-product / exact / mass-matched / assignment-shuffle | 仅胜marginal只支持结构监督；须胜root/mass才支持联合依赖，shuffle须更弱。固定endpoint、100epochs、历史batch8/accumulation4与scheduler语义不改；关键比较失败即停该配置，不扫scale/epoch挽救 |
| D4锚点—承诺证据绑定（候选） | 保持marked-CLS完整文本与flat head；拟用原生同语境多事件与支持词归属监督；普通supcon/类平衡/容量为强rivals | 先核train稀有类机会、offset与CoDE/SDIN/scope最近邻；不得把跨事件标签当蕴含标签或删词假造翻转。若只是普通contrast或标注不能识别归属，拒绝此候选；loss、臂数与power尚未冻结 |
| A4目标条件多正例监督（候选） | 保持完整候选与多真实原因，研究按目标/方向/subtype组织监督；普通hard mining/多正例contrast、SVRECI为强rivals | 先核train分组与假负例问题；不唯一原因softmax、不裁评测候选。恢复/损失正例及P/R同时报告；若仅靠全None降FP、普通contrast或shuffle同样有效，不支持机制；loss、臂数与power未冻结 |

## 资源分配、依赖与关键路径

4090重新为主执行机，优先已有pin和资产；5090保留原机checkpoint和既有特定任务许可。
同一比较族优先在4090同栈完成，所有臂使用相同可见GPU数量、有效batch、数值精度、
输入打包和优化步数。不同GPU运行不同臂，不把模型改成多卡DDP；硬件差异需记录。

- **4090空卡**：先完成C5原机资产复核和剩余成本；成本fixture可按独占输出并行。
  五臂训练准入后，按实际空卡与CPU/RAM/IO预算滚动排不同臂，每臂固定seed13；
  不是四卡固定承诺，不能用同卡挤占或未授权seed填满资源。
- **5090**：既有C5 decoder audit可原地有界收口，不阻断C5创新主线；C5成本/训练
  原许可保持，但当前不需要为恢复4090任务新造5090迁移适配。新D4/A4 GPU不擅自使用5090。
- **本地CPU**：文献、合同、轻量覆盖检查、测试与raw结果复算；大规模CPU/模型工作也放远端。
  C5长训练运行时可准备主表中D4/A4的文献与train信号，不能启动第二个未准入方法训练队列。
- **代码/权重**：4090远端落后与未跟踪目录先保全核源再同步已push代码；不clean。
  训练前重新核空卡、hash与本地三件套，torch相关测试须在远端真实执行。
  checkpoint留训练机，不跨机搬运；无自动等卡启动器；SSH失败按UNKNOWN处理。

关键路径为C41-R→B→A→T→V，再D4和A4各自的研究/准入/训练/归因。
C41-A包含两段：先设计准入，后TDD生产实现、真实测试与完整phase/code冻结；
最终method_admitted通过前不训练。已有许可不能替代科学门，成本PASS也不能替代准入。
原C41-S的5090迁移实现标deferred，保存历史，不伪装done。
