依据是 R1 §25.42 的强类型控制与双向残余错误、§25.49–§25.61 的机制/竞争解释、
§25.62–§25.63 的成本证据及其未闭合边界。当前不能声称新的方法收益。
审查同时服务后续 D4 表3-3、A4 表4-3，避免继续用基线恢复充当创新。

**可行性**：本地文档、冻结配置、入口源码与非权重证据可核；服务器事实见 §25.64。
目前 C5 候选的数据/监督接口有证据支持，完整训练预算、生产实现与执行合同尚未闭合。
4090 连接失败是运维障碍，不能据此判方法不可行；5090 的空卡也不能解除准入门。
本次没有增加 GPU、额外 seed 或跨机 checkpoint 搬运授权。

## 导师判断

项目积累了较完整的失败证据、可追溯资产和强控制，但三个旧方法家族尚未形成
通过主指标门的方法贡献。E3 已有成果按现行边界保留。当前最有价值的交付是
检验一个具体可证伪问题：**在相同输入、原架构和预算下，保留共享前件依赖的
exact 训练目标，是否比普通 soft-cluster 监督及整体概率增加更有效？**

该问题有研究意义，答案仍可能为负。精确递推的数学成立、真实梯度非零、成本通过，
都只是必要准备；只有官方主指标、强对照、负控与误差交换支持，才有方法价值。
最近邻差异沿用已有审查边界，不把“尚未检索到完全相同实现”写成已证明新颖。

当前管理风险是准备工作持续增长而决定性实验迟迟没有发生。每一项补验必须说明
它关闭哪个必要门、产出什么、何时停止。已经完成的 token、CPU parity、原架构
CUDA 和固定控制不复跑；CPU 等待工作只做现有缺口，不继续新增无关诊断。

## 给 Codex 的分阶段交付

| 顺位 | 必须完成的交付 | 验收与停止条件 |
|---|---|---|
| 1. 恢复可执行环境 | 查清5090未跟踪文件来源；核执行源码/配置/输入与原地模型；恢复4090连接后重新核卡。远端同步前保留未跟踪资产 | 成功读取机器身份、Git版本、GPU与compute PIDs；SSH失败记UNKNOWN。不能以本地HEAD代表远端已同步 |
| 2. 关闭预算门 | 接HANDOFF §0.3.5，完成固定五臂×两fixture结构/真实optimizer成本；另以独立身份补正式accumulation4周期、完整train的关系head/type块shape与总预算 | 单列cold/warm、allocated/reserved、optimizer state、各臂耗时、完整性审计开销与估算假设。OOM/fail留原产物；两fixture通过不自动等于全train预算通过 |
| 3. 给出R1裁决 | 整合机制差异、可部署输入、预算、已冻结条件power与敏感性；列出逐项证据，形成准入或具体阻断判断 | 条件power不能改称真实训练方差保证。必要条件齐全后才冻结新phase与生产执行合同；不得以成本PASS直接把method_admitted改为true |
| 4. 实现并检验 | 准入后复用官方Model，TDD完成生产训练/导出；本地三件套及远端真实测试通过后，冻结代码/config/input identity，启动同seed13的五臂 | 同pretrained、输入、类型policy、decoder、loss scale与固定endpoint；不把lr0成本hook带入非零学习率训练。各臂完成前不根据internal-dev分数挑参数、endpoint或臂 |
| 5. 作科学裁决 | 全臂endpoint后统一官方评分、document配对区间、四共指指标、三个关系任务及误差交换，独立复算并回填 | 按既有brief目标与护栏逐项裁决；关键比较失败保留负结果，停止该固定配置。停止候选不等于整个章节完成；替代路线先写主表，不复活封存家族 |

预算外推必须按各臂的真实步骤与shape记录，不能用marginal耗时代表exact，也不能
把lr0完整性检查开销算成生产训练成本。正式训练的学习率、batch、累积、scheduler
计数沿 R1 §25.62 的历史真实设置，不能照抄通用默认值。

## 五臂必须回答的科学问题

| 比较 | 能回答什么 | 不能越界的解释 |
|---|---|---|
| exact vs corrected-marginal | 加入这项结构监督是否改善同预算控制 | 单独胜出不能证明联合依赖贡献 |
| exact vs root-product | 保留联合依赖是否优于membership乘积 | 两臂必须同surrogate/scale/decoder |
| exact vs mass-matched | 收益是否超过总体pair概率量增加 | 不能把mass rival称为同forest的精确概率 |
| exact vs assignment-shuffle | 正确pair归属是否有用 | shuffle不是只切断共享祖先，不能作更窄因果主张 |
| exact vs 原typed强锚 | 是否超过当前有效强控制 | fixed-endpoint与旧best-dev的选择过程差异必须披露 |

主指标突破目标、共指护栏、归因区间和停止规则已经在候选brief与 R1 §25.55 冻结，
本次不另设门槛。文档bootstrap只说明此seed下评测文档不确定性，不能声称跨seed稳定。
若仅赢marginal却不赢root/mass，可以报告结构监督结果，但不能认作exact机制突破。
误差分析同时报告恢复/损失真链接及移除/新增假链接，不只挑改善的案例。

## 按现场资源执行

- **4090**：当前连接与卡况只认 §25.64。连接恢复后核空卡再接原r2入口；
  多张可用卡可并行不同病例或已准入的不同臂，固定seed不变。优先用原机已有资产。
- **5090**：当前快照只说明核查时可用。现有具体许可包括原C5 decoder audit、
  C-41原joint成本以及R1准入后的五臂训练（每任务不超过一天），不能扩到A4。
  r2结构成本迁移是否属于原joint成本许可须核原始授权范围，不能仅凭空卡自行认定。
  现r2入口硬编码4090 cwd/config，不能直接复制命令、删除guard或修改封存身份。
  如迁移成立，先在主表C-41注明本机适配，建立独立配置/合同/output并核本机pins，
  走TDD与相应CPU测试；无需搬已有checkpoint。正式训练还须单列5090本机预算与时限。
- **已授权decoder audit**可在核资产后收口，解释限于同分数换decoder；
  它不是新训练前置，不能替代主候选五臂。当前不启动、不重跑已完成smoke。
- **两机不可用时**：继续静态shape census、合同与预算分析；不本地跑GPU、
  不假造进程GONE，不设置未披露的等卡自动启动器。

## 后续章节与汇报要求

维持 C5 → D4 → A4。C5取得足以作路线裁决的证据并按队列回填后，才推进下一切片；
不要求为等待一个正结果而无限续修同一候选，也不把单个候选失败写成整章改善完成。

**D4**：以已恢复parity的linear作为控制，从五类残余错误及可部署输入选实质不同信号。
重新核最近邻机制与可证伪预测；旧causal-residual、tanh5与“完美边就能救”的解释不重开。
目标仍是官方五类macro-F1及强对照，不能仅提高多数类或重现baseline。

**A4**：先分清已观察到的召回坍塌与尚待验证的原因。原地冻结的train-only
共享梯度audit可以检验局部冲突，但不能证明历史Adam轨迹或唯一失败原因。
新的训练目标必须保护完整候选下的正例识别，匹配控制后再审机制、主指标和护栏；
不凭梯度符号设计新loss，也不在没有授权时把A4搬上5090。

每次接续汇报应交付：关闭的必要门及证据位置、尚欠的门、下一条具体动作、
资源与授权状态。每个实际结果都落results，主表/TASKS/TODO/HANDOFF按阶段同步，
逻辑提交并push。不要把代码行数、检查数量或GPU忙碌程度当作科研进度。

过程方法使用本地 `scientific-critical-thinking` / `hypothesis-generation`，
并按 `verification-before-completion` 核验交付；不把skill通过当科学结论。
